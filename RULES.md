# Canvas Rules Reference

1. Room names stay in merged A:C cells, rows 173-210.
2. H / Extra Bed stays blank.
3. PP room + SINGLE ROOM => separate Single row (except Adult Only).
4. DOUBLE ROOM+EXTRA BED => 3 adults.
5. Currency => A213.
6. Meal Plan => A218.
7. Exact child age decimals are preserved.
8. Adult Only => no child age, no child pricing, no Single/Double split.
9. Total-price room adult price changes can create occupancy-based room splits.
10. Max Occupancy comes from actual contract combinations.
